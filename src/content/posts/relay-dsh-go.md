DSH Go 是社区开发的 DeepSeek Harness 手机客户端。想在 Android 手机上用 429ONE 聊天，可以让 DSH 引擎在手机上运行，再由它把模型请求发送到中转站。整个过程都可以在手机上完成。你需要一枚 **429ONE 签发的 API Key**，以及这枚 Key 可调用的模型 ID。[DSH Go 项目说明](https://github.com/ccch1mneyyy/dsh-Go)

开始前，在手机浏览器登录 429ONE，准备好站点签发的密钥（API Key），并看一下账户可用的模型名称和接口说明。密钥是记账用的，等 App 询问 API Key 时只粘贴这串值。地址统一用 `https://api.429.one/v1`。**手机上不用安装电脑终端，也不用先运行第一篇的命令。** [站点入口](https://api.429.one/)

## 1. 下载 APK，打开手机里的 DSH Go

从项目发布页下载 APK。DSH Go 要求 Android 8.0 或以上，常见的 64 位安卓手机选 **arm64**。如果看到的是 GitHub 发布页，找到附件区 **Assets**（已折叠就点开），选择文件名含 `arm64` 且以 `.apk` 结尾的安装包。「Source code」是源代码，手机安装时应选 APK。下载后在浏览器的下载记录中点开文件；如果 Android 询问是否允许当前来源安装，核对文件来自项目发布页，再按系统提示完成安装。[Android 安装包](https://github.com/ccch1mneyyy/dsh-Go/releases/latest)

## 2. 在手机上启动本机引擎

1. 打开刚安装的 DSH Go，首次设置选 **本机**。引擎是 App 用来启动对话、发送模型请求的程序。按引导安装运行环境，建议预留约 1 GB 空间。
2. 等待安装完成并自动启动。之前跳过这一步的读者，进入 **设置 → 本机引擎 → 安装运行环境**。若已安装但显示停止，点「启动」。
3. 确认本机引擎已连接，再打开 **设置 → 模型**。若添加按钮不能用，先回引擎页面看启动提示，不必反复重输 Key。[项目文档：本机引擎](https://github.com/ccch1mneyyy/dsh-Go/blob/d73c679c37b40466827e22a55b46f3e0c74ca7a1/docs/guide/zh/03-engine-hosts.md)

这里有两个容易混淆的地址：**远程主机**用来连接另一台运行 DSH 的设备；**模型渠道的 Base URL** 才用来填写中转站地址。如果你本来就在用自己的远程 DSH，也可以继续使用，但接下来添加的渠道和密钥会保存在那台主机的引擎里。

## 3. 添加 429ONE 渠道

在 **设置 → 模型 → 添加渠道** 打开表单。「渠道」就是一份地址、密钥和模型的组合。看站点给你的模型说明：写着 **Responses** 就在 App 选 **Responses**；写着 **Chat Completions** 就选 **OpenAI**。如果没有说明，可以先用 **Responses** 测一条短消息；若返回路径不存在，再按文末的方法检查或改测另一种协议。

| 字段 | 填写内容 |
| --- | --- |
| 名称 | `429ONE`，方便稍后在聊天页找到 |
| 兼容协议 | `/v1/responses` 对应 **Responses**；`/v1/chat/completions` 对应 **OpenAI** |
| Base URL | `https://api.429.one/v1`，填到 `/v1` 为止 |
| API Key | 你在 429ONE 使用的密钥 |

填完密钥点 **获取模型**。列表出现后，勾选一个你有权限使用的文本模型，记下它显示的完整名称，稍后在聊天页找同一个名字。如果站点没有返回列表，点 **手动添加**，粘贴站点提供的完整模型 ID，保留大小写和前缀。至少添加一个模型，再点 **保存**。[项目文档：模型与渠道](https://github.com/ccch1mneyyy/dsh-Go/blob/d73c679c37b40466827e22a55b46f3e0c74ca7a1/docs/guide/zh/02-models.md)

保存后，回「设置 → 模型」，在「自定义」一组找到 **429ONE**。点进去应该至少能看到一个模型。如果没有，点右上角铅笔编辑，补上模型后再次保存。

## 4. 在对话里选中模型，发一条消息

1. 新建对话，在输入框输入 `/model` 打开「选择模型」。也可以点进手机输入框，再点下方显示的模型名称。
2. 在顶部选择 **429ONE**，再点一次下面的**具体模型**。只点渠道会筛选列表；点模型才会切换当前对话。
3. 发送「请只回复 OK」。收到回复后，按发送时间对照中转站的用量记录，确认这次请求用了自己的 Key。如果你收到回复且用量记录能对上，这台手机就接好了，以后发消息不用再填一次密钥。以后想换回原模型，再打开 `/model`，选回原渠道下的模型即可。[项目文档：对话操作](https://github.com/ccch1mneyyy/dsh-Go/blob/d73c679c37b40466827e22a55b46f3e0c74ca7a1/docs/guide/zh/01-chat.md)

## 如果能看到渠道，却收不到回复

- **找不到「添加渠道」**：先看当前引擎是否已连接。如果昨天配好、今天却找不到 429ONE，检查是否从本机切到了远程主机。
- **「测试连接」成功，发消息却报 404**：这个按钮只用已保存的 Key 读取模型列表。打开渠道详情，点右上角铅笔，重点核对生成接口的兼容协议，以及 Base URL 是否误填了完整的 `/responses` 或 `/chat/completions` 路径。
- **提示无权使用模型**：先核对当前对话选中的渠道和模型 ID，再用同一枚 Key 做第一篇的短请求。这样可以判断该查账号权限，还是回手机调整配置。
