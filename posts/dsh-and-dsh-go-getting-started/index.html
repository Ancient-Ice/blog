第一次用 DeepSeek Harness 和 DSH Go：从下载安装到收到第一条回复

2026-11-25
DeepSeek HarnessDSH Go入门教程

假设你手里有一张购物清单，想让 AI 帮你找出还没买的东西。用电脑时，你可以让它读取指定文件夹里的清单；用手机时，也可以把清单贴进聊天框直接问。下面从下载软件开始，做到这件事就算入门。手里只有一台设备也能跟着做，只读对应的那一节就好。

DSH 和 DSH Go 分别是什么？

DeepSeek Harness 是 DeepSeek 开发的开源 AI 工具，简称 DSH。它负责接收你的问题、连接你选的模型，并在你指定的文件夹里处理任务。模型负责读懂问题并生成回答。所以，安装完成能看到聊天窗口，选好可用的模型以后才能收到回复。

DSH Go 是社区基于 DeepSeek Harness 开发的手机应用。安卓手机可以自己运行 DSH，也可以连接一台已经运行 DSH 的电脑。本文选「本机」：整套流程用手机就能完成，提问时仍需要联网访问模型。DeepSeek Harness 项目 · DSH Go 项目

你手里的设备 从哪里开始
Windows 电脑或 Mac 电脑：下载安装 DeepSeek Harness
安卓手机 安卓：下载安装 DSH Go
Linux 电脑 使用浏览器版安装教程，做到页面打开后即可继续选模型
iPhone 截至 2026 年 11 月 25 日，DSH Go 项目说明中 iOS 版仍在开发和真机测试，尚无公开安装包。能用电脑的读者可以先走电脑路线

先决定用什么来回答你的问题

第一次使用，最省步骤的是在软件里选 DeepSeek 官方渠道，按提示登录账号，或填已有的 DeepSeek API Key。API Key 是一串让软件以你的账户调用模型的专用密钥。要创建官方 Key，可以在浏览器登录 DeepSeek 开放平台，进入「API keys」页面，创建并复制完整值，保存到自己的密码管理器。模型调用可能产生费用，先查看账户可用额度；网页登录密码只在登录页使用。DeepSeek 开放平台密钥页

如果手里已有 429ONE 的 Key，也可以用它做本文的练习。这串 Key 要填进「自定义」渠道，还要准备站点允许调用的模型名称。下文在需要分流的地方给了具体入口。两种方式任选一种即可。

电脑：下载安装 DeepSeek Harness

第一步：挑对安装包

怎么确认自己的电脑型号 点哪个下载
Windows 打开「设置 → 系统 → 系统信息（关于）」，在「系统类型」里看到「基于 x64 的处理器」 Windows x64 安装程序（.exe）
Mac 点屏幕左上角苹果标志 →「关于本机」，「芯片」一栏写着 Apple M 系列 Apple 芯片版（.dmg）
在「关于本机」看到「处理器」为 Intel Intel Mac 版（.dmg）

以上是项目发布文档列出的固定下载地址。如果你的 Windows 机器显示 ARM，或者不确定该选哪一项，可改走电脑浏览器版教程。桌面版发布文档

第二步：安装并打开

  • Windows：在浏览器下载记录里点开刚下载的 .exe，保留默认安装位置，点「安装」。完成后勾选启动应用，或在开始菜单搜索 DeepSeek Harness 打开。
  • Mac：打开访达的「下载」文件夹，双击 .dmg。在弹出的窗口里将应用图标拖到「应用程序」，等复制结束，再到「应用程序」双击 DeepSeek Harness。

看到欢迎页就说明程序已经启动。桌面安装包自带运行环境；走这条路线可以一直用鼠标操作。

第三步：接上模型

  1. 使用官方账号：在欢迎页选择登录，按浏览器提示完成授权，然后回到 DeepSeek Harness 窗口。
  2. 如果使用官方 API Key：在欢迎页选择 API Key 入口，粘贴完整密钥，点「保存并继续」。如果已经进了主界面，也可以在「设置 → 模型」找到 DeepSeek API 卡片，填好并保存。
  3. 如果使用 429ONE：在欢迎页的 API Key 页面点「稍后配置」。进入主界面后打开「设置 → 模型 → 添加模型提供商 → 自定义模型 API」，将基础地址填为 https://api.429.one/v1，再填站点 Key，并按站点支持的协议添加模型。每个字段的示例见429ONE 模型配置教程。

上面三项只做与你手里的账户或 Key 对应的那一项。保存后打开模型选择器，应能看到所选提供商下的模型名称。桌面欢迎页说明

第四步：让它读一张你自己写的清单

  1. 在桌面空白处右键新建文件夹，命名为 DSH练习。工作区就是你指定给 DSH 处理的文件夹，第一次用这个练习目录即可。

  2. Windows 打开「记事本」；Mac 打开「文本编辑」，在「格式」菜单选「制作纯文本」（已经是纯文本就跳过）。写下下面两行，用「文件 → 保存」存进 DSH练习，文件名填 清单.txt。

    已买：苹果、牛奶
待买：鸡蛋、面包

  3. 回到 DSH，点「选择工作区」，添加并选中桌面上的 DSH练习。新建会话，选好模型，在聊天框输入「请读取这个文件夹里的清单.txt，只告诉我还有哪两样东西要买，不用修改文件」，点发送。

  4. 如果出现读取文件的确认框，核对它指向刚才的练习目录再同意。回复中出现鸡蛋、面包，就完成了从连接模型到读取自己文件的第一次练习。下次从开始菜单或「应用程序」打开 DSH，选回这个工作区即可。

安卓：下载安装 DSH Go

第一步：下载 APK 并安装

APK 是安卓的应用安装文件。 本机运行要求 Android 8.0 或以上，项目建议预留约 1 GB 空间。系统版本通常可以在手机「设置 → 关于手机」里查看。

  1. 在手机浏览器打开项目下载页。常见的 64 位安卓手机选 Android arm64。如果改从 GitHub 下载，在发布页展开 Assets，点文件名含 arm64、以 .apk 结尾的那一项。Source code 是给开发者的源代码。DSH Go 下载页 · GitHub 安装包
  2. 下载完成后点浏览器里的文件，或到手机「文件管理 → 下载」找到它。系统若询问是否允许当前浏览器或文件管理器安装应用，核对文件来源后按提示授权，再返回安装界面点「安装」。
  3. 看到「安装完成」后点「打开」。第一次启动选择 本机。跟随引导安装运行环境，等待引擎启动。「引擎」是 App 里负责运行 DSH 的部分。之前跳过了引导，也可以到「设置 → 本机引擎」点「安装运行环境」。

检查点：打开「设置 → 本机引擎」，确认本机已启动并连接。第一次聊天无需开启无障碍或手机操控权限。项目的本机引擎指南

第二步：选一个能用的模型

  1. 打开 设置 → 模型。使用 DeepSeek 的读者，在「官方」分组里点 DeepSeek。选「用 DeepSeek 账号登录」并完成浏览器授权，或选「DeepSeek API Key」填入官方密钥。
  2. 如果你使用 429ONE，改点 添加渠道，名称填 429ONE，Base URL 填 https://api.429.one/v1，API Key 填站点密钥。按站点说明选协议：Chat Completions 对应 OpenAI，Responses 对应 Responses。点「获取模型」，勾选一个可用模型并保存。若站点没返回列表，可点「手动添加」填入站点提供的完整模型 ID。429ONE 安卓逐项填写示例
  3. 回到聊天页，打开左侧对话列表，点 新对话。点进输入框，再点输入框下方的模型名；也可以输入 /model 打开「选择模型」。先点刚才设置的渠道，再点一次它下面的具体模型。回到聊天页，确认显示的是你选中的模型名。

第三步：在手机上收到第一条回复

把下面这句话整个复制进聊天框，点发送键：

我的购物清单是：已买苹果、牛奶；待买鸡蛋、面包。请只列出还要买的两样东西。

回复中应该有鸡蛋、面包。这一步说明手机已经能用选定的模型发出问题并收到回答。下次打开 DSH Go，回到「对话列表」就能找到这次练习；要换个话题，点「新对话」即可。DSH Go 对话指南

卡在哪一步，就查哪一项

你看到什么 接下来做什么
电脑能打开，聊天框却不能输入 回到主界面选中一个工作区，在新会话里选中具体模型，再点聊天框。
电脑回答“找不到清单.txt” 在资源管理器或访达打开练习文件夹，确认文件就在里面。检查是否存成了富文本或多了一层 .txt 后缀，再选一次工作区。
手机上「添加渠道」不能点 打开「设置 → 本机引擎」，看是否装好并连接。装好但已停止就点「启动」，等连接完成再返回。
发送后提示 401、密钥无效 回到模型设置，确认密钥填在签发它的渠道里，重新粘贴完整值并保存；再回到会话，重新选中该渠道下的模型。
能列出模型，但发送时提示余额或额度不足 登录该密钥所属平台查看账户额度。列出模型和实际生成回复是两次不同的请求，后者可能计费。
