接入中转站 ⑤：在 Android 手机上的 DSH Go 里使用 429ONE

2026-11-25
中转站接入DSH Go

DSH Go 是社区开发的 DeepSeek Harness 手机客户端。想在 Android 手机上用 429ONE 聊天，可以让 DSH 引擎在手机上运行，再由它把模型请求发送到中转站。整个过程都可以在手机上完成。你需要一枚 429ONE 签发的 API Key，以及这枚 Key 可调用的模型 ID。DSH Go 项目说明

1. 在手机上启动本机引擎

从项目发布页下载 APK。DSH Go 要求 Android 8.0 或以上，常见的 64 位安卓手机选 arm64。首次打开 App 时选择在本机运行，按提示安装内置运行环境，建议预留约 1 GB 空间。等引擎连接成功，再打开 设置 → 模型。Android 安装包

这里有两个容易混淆的地址：远程主机用来连接另一台运行 DSH 的设备；模型渠道的 Base URL 才用来填写中转站地址。如果你本来就在用自己的远程 DSH，也可以继续使用，但接下来添加的渠道和密钥会保存在那台主机的引擎里。

2. 添加 429ONE 渠道

在 设置 → 模型 → 添加渠道 打开表单。假设你已经用某个模型成功请求过 /v1/responses，就按下表填写；如果之前测通的是 /v1/chat/completions，只需把「兼容协议」改选 OpenAI。还不确定协议时，可以先看第一篇的请求示例。

字段 填写内容
名称 429ONE，方便稍后在聊天页找到
兼容协议 /v1/responses 对应 Responses；/v1/chat/completions 对应 OpenAI
Base URL https://api.429.one/v1，填到 /v1 为止
API Key 你在 429ONE 使用的密钥

点 获取模型，勾选要用的模型。如果站点没有返回列表，点 手动添加，粘贴站点提供的完整模型 ID，保留大小写和前缀。至少添加一个模型，再点 保存。项目文档：模型与渠道

3. 在对话里选中模型，发一条消息

  1. 新建对话，在输入框输入 /model 打开「选择模型」。也可以点进手机输入框，再点下方显示的模型名称。
  2. 在顶部选择 429ONE，再点一次下面的具体模型。只点渠道会筛选列表；点模型才会切换当前对话。
  3. 发送「请只回复 OK」。收到回复后，按发送时间对照中转站的用量记录，确认这次请求用了自己的 Key。以后想换回原模型，再打开 /model，选回原渠道下的模型即可。项目文档：对话操作

如果能看到渠道，却收不到回复

  • 找不到「添加渠道」：先看当前引擎是否已连接。如果昨天配好、今天却找不到 429ONE，检查是否从本机切到了远程主机。
  • 「测试连接」成功，发消息却报 404：这个按钮只用已保存的 Key 读取模型列表。打开渠道详情，点右上角铅笔，重点核对生成接口的兼容协议，以及 Base URL 是否误填了完整的 /responses 或 /chat/completions 路径。
  • 提示无权使用模型：先核对当前对话选中的渠道和模型 ID，再用同一枚 Key 做第一篇的短请求。这样可以判断该查账号权限，还是回手机调整配置。
